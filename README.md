# 健身動作資料庫 (Exercise Library)

1324 個健身動作的資料庫網站，附動作示範動畫 (animated WebP)。

## 使用方式

純靜態網站，無後端、無資料庫：

- `index.html` — 主頁面（篩選 / 搜尋 / 收藏 / 明暗主題）
- `data/exercises.json` — 動作資料（中英對照）
- `images/` — 1324 張動作縮圖 (JPG)
- `anims/` — 1324 個動作示範動畫 (WebP)

收藏功能使用瀏覽器 localStorage，不需伺服器。
